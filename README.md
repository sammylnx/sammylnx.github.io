# sammylnx.github.io

Personal site and blog of Saumojit (Sammy) Goswami, built with Jekyll and published on GitHub Pages.

- **Writing a post:** see [HOW_TO_POST.md](HOW_TO_POST.md).
- **Site settings** (title, links, number of posts on the home page): `_config.yml`
- **About page:** `about.md`
- **Look and feel:** `assets/css/style.css` (colours are at the top)

Every push to `main` rebuilds the site through `.github/workflows/pages.yml`.
